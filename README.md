# لقطة تركية — Turkish Scenes

تطبيق iPhone منفذ بـSwiftUI لتعلم التركية من مقاطع فيلم «معجزة في الزنزانة رقم 7»، بواجهة عربية ووسوم نطق عربية/تركية ودعم VoiceOver. الحد الأدنى المستهدف iOS 16.

**حالة التطوير:** الكود والتجارب على الفرع `dev/ios-app-20261101` في [طلب الدمج المسودة](https://github.com/dukkanai/turkish-scenes/pull/1). توجد نسخ TestFlight داخلية؛ لا يوجد نشر عام في App Store. الفرع الرئيسي قد يعكس الوثائق الأقدم إلى أن يُدمج العمل صراحة.

## ما يعمل
- عرض النص التركي والترجمة والشرح، ومشغل YouTube مضمّن ومحدد بتوقيت المقطع، دون تنزيل الفيديو.
- تنقل حر بين المقاطع، وتدريب كتابة المفردات أو اختيارات المفردات والعبارات.
- تصحيح تركي، تقدم ومحاولات وأخطاء محفوظة محليًا، ومراجعة أخطاء مستقلة.
- أزرار ونصوص عربية/تركية ملائمة لقارئ الشاشة وتكبير الخط، وإعدادات محدودة مع تأكيد قبل حذف التقدم.
- بناء واختبارات وتوقيع داخلي عبر GitHub Actions على macOS فقط.

## المحتوى وحدود المراجعة
المصدر الأصلي محفوظ دون تغيير: 1,666 مقطعًا و7,297 ظهورًا للكلمات. المراجعة النصية لبنك المفردات تشمل كل المقاطع: 6,665 سؤال مفردة مؤهلًا و632 ظهورًا مستبعدًا أو معلّقًا صراحة. تبقى التهجئات المعلّقة ظاهرة مع تفسيرها ولا تُقدّم كأسئلة صحيحة مؤكدة. أسماء الأشخاص محفوظة وفق سياسة المحتوى.

اكتملت أيضًا مراجعة أهلية العبارات لكل المقاطع: 1,162 سؤال عبارة في 1,160 مقطعًا، و506 مقاطع متجاوزة بأسباب صريحة. مجموع الأسئلة المؤهلة 7,827. بنك العبارات منفصل عن كتابة المفردات. الأعداد والملفات الفعلية موثقة في `App/Resources/reviewed-manifest.json` و`reviewed-phrases-manifest.json` وتقارير `docs/CONTENT_REVIEW_*.md`. المراجعة النصية ليست تدقيقًا سمعيًا بصريًا لكل توقيت ولا اعتمادًا من متحدث أصلي.

## البناء والتحقق
- `project.yml`: تعريف XcodeGen، ومجلد `App` للتطبيق.
- `.github/workflows/ci.yml`: فحوص التصحيح والحفظ والنطق والأمان والمحتوى، وبناء محاكي وسموك تنقل/استئناف.
- `.github/workflows/testflight.yml`: الاختبارات ثم الأرشفة والتوقيع والرفع من بيئة إصدار محمية.
- بيئة البناء الموثقة: macOS 15، Xcode 26.1.1، محاكي iOS 18.5. iOS 16 حد بناء مستهدف، وليس نتيجة اختبار تشغيل فعلية على iOS 16.
- لا تُضمّن مفاتيح Apple أو الشهادات أو ملفات تقدم شخصية أو نواتج البناء في المستودع.
