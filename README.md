# لقطة تركية — Turkish Scenes

تطبيق iPhone بواجهة عربية لتعلّم التركية بالسماع: كلمات، عبارات يومية، وقواعد. يستبدل هذا الاتجاه تجربة الأفلام السابقة؛ اسم التطبيق ومعرّف الحزمة لم يتغيرا.

## النطاق المعتمد

- ما لا يقل عن 1,200 كلمة تركية متميزة، ومعها 250 عبارة يومية على الأقل، بمعانٍ عربية وأمثلة أصلية.
- خمس كلمات في كل درس، والتكرار حتى اجتياز أسئلة الدرس. العبارات مجموعات من خمس والقواعد قاعدة واحدة في الدرس كخيار تصميمي.
- شرح صوتي وأسئلة وإجابات وتصحيح باستخدام `gpt-realtime-2.1`، مع حفظ التقدم ومراجعة الأخطاء.
- إضافة كلمات شخصية بالصوت بعد مراجعة الاقتراح وتأكيده.
- يدخل المستخدم مفتاح OpenAI الخاص به داخل التطبيق، ويُحفظ في Keychain على هاتفه فقط.
- iOS 16 فأعلى، واجهة RTL وVoiceOver، وتحديث داخلي عبر TestFlight بعد التحقق.

## الحالة الفعلية

هذه الوثائق تحل محل وثائق تجربة الأفلام. تنفيذ التجربة الجديدة قيد الإعداد والتحقق، ولا يعني رفع الوثائق أن الجلسات الصوتية قد اجتازت البناء أو اختبار الجهاز. راجع [حالة التنفيذ](docs/STATUS.md) قبل الاعتماد على أي ادعاء جاهزية.

لم يُنشر إصدار عام، ولم يُجرَ اختبار API مدفوع لهذه الميزة. لا تُعامل نجاحات التطبيق القديم كأدلة نجاح للتطبيق الجديد. تاريخ Git يحتفظ بالمحتوى والكود السابقين؛ لا يتطلب الانتقال حذف تقدم المستخدم القديم.
