# لقطة تركية — Turkish Scenes

تطبيق iPhone مخطط لتعلم التركية من مقاطع الأفلام، بواجهة عربية ودعم VoiceOver، يعمل على iOS 16 فأعلى. المستودع العام: [dukkanai/turkish-scenes](https://github.com/dukkanai/turkish-scenes).

**الحالة: الوثائق ومصدر المحتوى جاهزان، والمستودع العام منشأ.** لا يوجد تطبيق منفذ أو إعداد CI فعلي. أذن المستخدم برفع ملفات المشروع الحالية لنقل العمل إلى سيرفر آخر؛ بدء برمجة التطبيق ينتظر تعليماته.

## استخدام المشروع على سيرفر آخر

مع توفر Git، نزّل المشروع وافتح مجلده:

```bash
git clone https://github.com/dukkanai/turkish-scenes.git
cd turkish-scenes
```

ابدأ بقراءة `docs/EXECUTION_STATUS.md` ثم `docs/IMPLEMENTATION_PLAN.md` لمعرفة الحالة والخطوة التالية. لا توجد حزم لتثبيتها أو تطبيق لتشغيله حاليًا. لجلب التحديثات لاحقًا من داخل المجلد استخدم `git pull --ff-only`. تنزيل المستودع العام لا يحتاج تسجيل دخول، ورفع تغييرات إليه يحتاج صلاحية GitHub.

يمكن تحرير المشروع من سيرفر Linux؛ بناء تطبيق iPhone سيحتاج macOS وXcode محليًا أو عبر GitHub Actions عند إعدادها لاحقًا. إعدادات `.codex` المحلية ومفاتيح Apple غير مضمّنة في المستودع.

## المحتوى الأول

- الفيلم: معجزة في الزنزانة رقم 7.
- [رابط الفيلم المسجل](docs/films_links.md).
- [المصدر التركي والعربي وشرح المفردات](docs/srt/7_Koğuştaki_Mucize.srt).
- الفيديو يُشغّل مباشرة من YouTube بالتوقيت؛ لا يُنزّل للاستخدام دون اتصال.
- النصوص والتمارين والتقدم محفوظة محليًا. الأفلام الجديدة تضاف بتحديثات التطبيق.

المصدر الحالي يحوي 1666 مقطعًا بحسب فحص البنية، وليس بالضرورة 1666 وحدة اختبار صالحة. تحديد المقاطع التعليمية وصلاحية الأسئلة ومطابقة توقيت الفيلم أعمال لاحقة موضحة في الخطة.
