## قرارات المستخدم المعتمدة

- الاسم «لقطة تركية»، والمستودع العام `turkish-scenes`.
- iPhone، ودعم iOS 16 فأعلى؛ الهاتف الحالي XS Max، وحساب Apple Developer متوفر.
- النص والترجمة والمفردات من SRT، بالصيغة المكتوبة والتكرار داخل كل مقطع.
- تضمين الأسماء؛ استبعاد الموسيقى والضوضاء والأصوات غير المفيدة للتعلم.
- كتابة مفردات فقط، واختيارات مفردات وعبارات؛ العربية للسؤال والتركية للإجابة.
- السابق والتالي دون اشتراط الإتقان؛ الصحيح ينتقل تلقائيًا، والخاطئ يعرض الصحيح وينتظر التالي.
- تقدم وأخطاء محليان، وفيديو مباشر من YouTube دون تنزيل.
- فيلم واحد للإطلاق؛ إضافة المحتوى بالتحديثات؛ GitHub Actions على macOS وTestFlight قبل المتجر.

## تفاصيل تخطيطية افتراضية وليست طلبات جديدة من المستخدم

- SwiftUI وCodable وتخزين JSON وWKWebView، دون مكتبات طرف ثالث ابتداءً.
- ثلاثة أقسام رئيسية؛ شاشة تدريب موحدة؛ أربعة خيارات عند إعداد سؤال اختيار.
- التصحيح التركي الدقيق مع تسامح الفراغات والترقيم الطرفي وحالة الأحرف وفق اللغة.
- حل الخطأ بعد إجابة صحيحة في مراجعة مستقلة، مع حفظ تاريخه وإعادة فتحه إذا تكرر.
- وحدة التعلم مقطع المصدر، دون دروس من خمس عبارات أو دمج تلقائي.
- أدوات البناء تحدد عند التنفيذ حسب التوفر ومتطلبات Apple، ويبقى الحد الأدنى iOS 16.
