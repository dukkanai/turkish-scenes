# متطلبات التطبيق الصوتي

آخر تحديث: 2026-11-06.

## القرارات الصريحة

استبدال تجربة الأفلام بتعلّم تركي صوتي بواجهة عربية. الحد الأدنى 1,200 كلمة متميزة و250 عبارة يومية. كل درس كلمات يضم خمس كلمات؛ يُسمع النطق والمعنى والأمثلة، ثم يجيب المتعلم شفهيًا، وتُعاد أخطاؤه حتى يجتاز المجموعة قبل التالية. تشمل التجربة قواعد مع شرح وسؤال وتصحيح. يُحفظ التقدم وتُراجع الأخطاء، ويُدخل المستخدم مفتاحه الشخصي داخل التطبيق. المسار المصرح يصل إلى TestFlight، ولا يشمل نشر App Store عامًا أو استدعاءات API مدفوعة أثناء التطوير دون موافقة مستقلة.

## خيارات التصميم

- أقسام الدروس: كلمات، عبارات، قواعد. خمسة عناصر للدرس في الكلمات والعبارات؛ قاعدة واحدة للقواعد.
- سياسة اجتياز أولية: إجابتان صحيحتان مستقلتان لكل عنصر. الخطأ يصفر عدّ ذلك العنصر؛ الإجابة غير المسموعة أو الغامضة لا تُحتسب.
- مراجعة الأخطاء أولًا ثم المراجعات المستحقة. المراجعة الأولى بعد يوم، ثم بعد ثلاثة أيام؛ هذا جدول تدريب بسيط وليس خوارزمية مثبتة علميًا لكل متعلم.
- تصفح المحتوى متاح دون اتصال AI؛ التدريب الصوتي يحتاج إنترنت ومفتاحًا وإتاحة النموذج في حساب المستخدم.
- يبدأ الدرس بالشرح. يتاح بدء الاختبار صوتيًا أو بزر واضح. لا تُعرض إجابة السؤال أثناء الاختبار قبل التصحيح.
- لا ينتقل النموذج إلى درس جديد من تلقاء نفسه. التطبيق يملك حالة الدرس والإتقان.

## الوصول والاستخدام

العربية RTL، والنصوص التركية باتجاهها ووسم نطقها التركي. أزرار بدء وإيقاف وكتم وتكرار وإغلاق بأسماء صريحة. لا يتوقف تدفق التعلم على لون أو رؤية النص أو مؤقت قصير. يتوقف الميكروفون والاتصال عند مغادرة التطبيق، أو مقاطعة صوتية، أو فصل سماعة، ولا تبدأ إعادة اتصال مدفوعة تلقائيًا.

المفردة الشخصية التي يطلبها المستخدم بصوته تظهر مع معناها ومثالها وترجمته، ولا تُحفظ قبل التأكيد. اقتراح النموذج ليس اعتمادًا لغويًا بشريًا. الاحتفاظ باسم التطبيق ومعرّف الحزمة لا يعني الاحتفاظ بواجهة الأفلام.
