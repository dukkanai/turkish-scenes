# البناء وTestFlight

المستودع https://github.com/dukkanai/turkish-scenes . فرع التطبيق `dev/ios-app-20261101` وطلب المسودة #1. هوية الحزمة `dev.nextaura.turkishscenes` محفوظة لتحديث التطبيق نفسه. تغيير الاسم ليس ضمن الإذن الحالي.

## مسار العمل

- إعداد التغييرات واختبار البيانات محليًا دون مفاتيح API.
- رفع commit مراجعة على فرع التطوير، دون دمج تلقائي أو نشر عام.
- GitHub macOS15 وXcode26.1 لبناء SwiftUI ومحاكي iPhone؛ `project.yml` يولّد المشروع بواسطة XcodeGen.
- فحوص التعلم الصوتي الجديدة يجب أن تحل محل smoke الخاص بواجهة الأفلام قبل الاعتماد على CI.
- لا يُعاد استعمال نجاح CI لتجربة الأفلام كدليل على النسخة الجديدة.

## التوقيع

يستخدم المسار القائم بيئة GitHub المحمية `turkish-scenes-testflight`. تبقى الأسرار في إعدادات البيئة؛ لا تُقرأ قيمها أو تنقل إلى المحادثة أو المصدر. `ci/testflight.sh` ينشئ Keychain مؤقتًا، ويتحقق من الحزمة وملف التوقيع، ويرفع محاولة واحدة ثم ينظف الملفات. لا تغييرات صلاحيات أو أسرار جديدة ضمن هذا التحديث.

## تسليم النسخة

1. نجاح الاختبارات والبناء على commit المرشح، مع توثيق الاختبارات التي لم تنفذ.
2. الأرشفة والتوقيع والتحقق والرفع الداخلي برقم build فريد.
3. التحقق من معالجة Apple وظهور النسخة في مجموعة الاختبار المعتمدة. إذا كان الرفع غير مؤكد، افحص الحالة قبل إعادة المحاولة.
4. إبلاغ المستخدم بالنسخة الفعلية وحدودها. لا ادعاء أنه ثبتها أو جربها دون دليل.

المستخدم أذن بالوصول إلى TestFlight. لا يشمل ذلك App Store عامًا، مختبرين خارجيين جدد، شراء خدمات، أو استدعاء API مدفوع دون موافقة. عدم توفر macOS محليًا لا يمنع استخدام CI المصرح، لكنه يمنع ادعاء اختبار الجهاز وVoiceOver محليًا.
