# GitHub والبناء والتوزيع

## المسار الحالي
المستودع العام هو [dukkanai/turkish-scenes](https://github.com/dukkanai/turkish-scenes). التطبيق على فرع `dev/ios-app-20261101` وطلب دمج مسودة؛ لا يعني وجود الكود نشره عامًا على App Store. كل تنفيذ التطبيق واختباراته وأرشفة iOS يجري على GitHub macOS، دون الاعتماد على سيرفر التطبيق أو Codex.

## CI المنفذ
- `.github/workflows/ci.yml`: يعمل لطلبات الدمج وpush إلى main والتشغيل اليدوي؛ صلاحية المحتوى للقراءة، وإلغاء تشغيل CI الأقدم لنفس الفرع.
- `.github/workflows/testflight.yml`: إصدار داخلي من الفرع المصرح، ببيئة `turkish-scenes-testflight` المحمية. لا يرفع كل تعديل محتوى تلقائيًا؛ راجع شروط تشغيل الملف.
- macOS 15 وXcode 26.1.1 موثقان في نتائج البناء، ومحاكي iOS 18.5 للاختبار. حد نشر التطبيق iOS 16 مستقل عن SDK ولا يثبت اختبار iOS 16.
- تُنفذ فحوص المنطق والحفظ والنطق والأمان والمحتوى وبناء المحاكي وسموك الواجهة قبل الأرشفة في مسار الإصدار.

## التوقيع والأسرار
هوية التطبيق `dev.nextaura.turkishscenes`. إعدادات التوقيع والرفع موجودة في بيئة GitHub المحمية؛ لا تُطلب قيم المفاتيح في محادثة أو ملف عام. ينشئ `ci/testflight.sh` keychain ومجلدًا خاصًا مؤقتين، ويتحقق من هوية التطبيق وملف provisioning، ثم يوقّع ويصدر ويتحقق ويرفع وينظف الموارد المؤقتة. لا تُرفق مواد التوقيع كـartifacts ولا تُطبع قيمها.

لا تُسحب شهادات أو مفاتيح مشتركة مع مشروع آخر لمجرد إيقاف ذلك المشروع. تغييرات الوصول أو بيانات الاعتماد تخضع لإذنها المستقل.

## تحقق TestFlight
1. تحديد commit المرشح ونجاح فحوصه نفسها، لا الاكتفاء بفرع أو نتيجة قديمة.
2. اعتماد بيئة الإصدار المصرح بها، ثم الأرشفة والرفع برقم build فريد.
3. التحقق من اكتمال معالجة Apple، ثم إضافة النسخة إلى مجموعة الاختبار الداخلية المقصودة بعد مراجعة عضويتها.
4. التحقق من حالة Testing، وإبلاغ المستخدم بالنسخة المتاحة وحدود الاختبار.
5. لا تُدّعى نسخة مثبتة أو مقبولة على الهاتف دون دليل أو إفادة المستخدم.

الإصدارات هنا داخلية فقط؛ لا مختبرين خارجيين أو رابط دعوة عام أو إرسال App Store تلقائي. لا تُلغى معاينات سليمة لمجرد وجود نسخة أحدث.

## التحديثات والخصوصية
المعرفات ثابتة، والتقدم محلي ولا يُستبدل بملف افتراضي. تحديث البنك لا يُعادل حذف تقدم المستخدم. حذف التقدم إجراء داخل الإعدادات مع تأكيد واضح. النص والتدريب محليان، لكن YouTube طرف ثالث يتلقى اتصالات المشغل؛ لا توصف التجربة بأنها بلا اتصال خارجي.

قبل نشر المتجر يلزم استكمال وتحقق حقوق المحتوى والترخيص والدعم والخصوصية والتصنيف العمري والمواد التسويقية ومراجعة الأجهزة والسيناريوهات غير المختبرة. علنية المستودع لا تمنح ترخيصًا تلقائيًا.
