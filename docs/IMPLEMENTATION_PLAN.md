# خطة تنفيذ لقطة تركية

التاريخ: 2026-11-01. النسخة: 1.0. الحالة: خطة مكتوبة؛ التنفيذ غير مصرح ببدئه بعد.

## النتيجة المطلوبة

تطبيق iPhone أصلي بسيط، يدعم iOS 16 فأعلى، ويتيح تعلم التركية من الفيلم الحالي وتشغيل مقاطعه من YouTube، والتدرب بالكتابة والاختيارات، وحفظ التقدم والأخطاء محليًا. يمكن تنفيذ الرحلة الأساسية كاملة باستخدام VoiceOver. يضاف كل فيلم لاحق كمحتوى ضمن إصدار جديد.

الأسماء المعتمدة: «لقطة تركية» للتطبيق، و`turkish-scenes` للمشروع والمستودع العام. تحديث لاحق للتوثيق: أذن المستخدم بإنشاء المستودع ورفع ملفات المشروع الحالية، وقد أُنشئ تحت حساب `dukkanai`. مشروع Xcode وسير عمل GitHub Actions ورفع نسخة إلى Apple ما زالت مؤجلة؛ راجع [الحالة الحالية](EXECUTION_STATUS.md).

## مبادئ التنفيذ

1. استخدام SwiftUI ومكونات النظام، ومشغل WKWebView صغير، وتخزين JSON محلي؛ لا خادم ولا تسجيل دخول ولا مكتبات خارجية دون حاجة مثبتة.
2. اختصار الكود بتوحيد الشاشة والمنطق المشترك. لا تُضغط الأسطر أو تُحذف معالجة الأخطاء للوصول إلى عدد مصطنع من الأسطر.
3. مصدر المحتوى محفوظ كما هو. التصفية والتوضيحات الخاصة بالاختبارات طبقة منفصلة قابلة للتتبع.
4. تسبق تجربة الفيديو وإمكانية الوصول استكمال الواجهات؛ تعطل هذين الشرطين يمنع اعتبار المنتج جاهزًا.
5. الاختبارات تركز على التحويل والتصحيح والحفظ والانتقال وإمكانية الوصول، دون بنية اختبار ضخمة للمظاهر البسيطة.
6. لا يثبت اجتياز بناء المحاكي وحده صلاحية التطبيق على iPhone أو اكتمال دعم VoiceOver.

## طريقة تسليم واستلام المرحلة

عند نهاية كل مرحلة يقدم المنفذ تقريرًا قصيرًا يتضمن:

- المخرجات وروابط الملفات أو commit ونسخة TestFlight إن وجدت.
- حالات القبول المنفذة ونتيجتها، والجهاز والنظام وأداة البناء المستخدمة.
- خطوات تجربة واضحة للمستخدم، مع رحلة VoiceOver في المراحل المرئية.
- العيوب المتبقية وأثرها، وما لم يُختبر ولماذا.
- نتيجة الاستلام: جاهزة للتجربة، أو اجتازت الاختبارات، أو مقبولة من المستخدم، أو تحتاج إصلاحًا. لا تُخلط هذه الحالات.

استلام المرحلة يثبت جودة مخرجاتها، ولا يُفهم منه إذن جديد بالنشر العام للتطبيق. بعد صدور أمر التنفيذ يُعمل ضمن نطاقه دون طلب تأكيد لكل تعديل روتيني؛ تُرفع فقط القرارات التي تغيّر النطاق أو تحتاج معلومات غير متاحة. الوثائق الحالية لا تفرض توقفًا مصطنعًا عند كل مرحلة.

## حدود الإصدار الأول

فيلم واحد، واجهة عربية، كتابة واختيارات، تخزين محلي، ودعم iPhone. لا مزامنة iCloud أو خادم أو تقييم نطق أو تنزيل فيديو أو استيراد من المستخدم أو بوابة إدارة محتوى. لا مدفوعات أو اشتراكات داخل النطاق الحالي؛ سعر المتجر النهائي يُحسم عند تجهيز النشر ولا يعطل التطوير.

لا نعتمد تقسيمًا إلى دروس من خمس عبارات؛ الوحدة الأساسية هي المقطع كما في المصدر. لا يُدمج مقطعان تلقائيًا لأن المستخدم اعتمد المفردات وفق كل مقطع. يمكن إظهار سياق مجاور عند الحاجة دون تغيير معرفات المقاطع أو إجاباتها.
