# حالة التنفيذ

آخر تحديث: 2026-11-06.

## المنفذ في المصدر

استُبدلت واجهة الأفلام بتجربة صوتية للكلمات والعبارات والقواعد. بقي اسم التطبيق ومعرفه وملفات تقدم المستخدم السابقة دون تغيير أو حذف. أزيلت مصادر تجربة الأفلام من النسخة الحالية؛ تاريخ Git يحتفظ بها.

- 1,280 مدخلًا لغويًا متفردًا، منها 1,210 كلمات مفردة و70 تركيبًا معجميًا، في 256 درسًا؛ و250 عبارة يومية منفصلة في 50 درسًا؛ و20 درس قواعد.
- أمثلة أصلية وترجمات عربية، مع مراجعة نصية آلية وليست اعتماد متحدث أصلي.
- محرك درس يتطلب إجابتين صحيحتين لكل عنصر، ويعيد الخطأ ويؤجل غير الواضح، مع معرفات تمنع احتساب تقييم مكرر أو قديم.
- حفظ ذري مستقل ونسخة سابقة وحماية من الكتابة فوق ملفات فاسدة؛ لا تسجيل للصوت أو نص الإجابات.
- مفتاح شخصي في Keychain، واتصال WebSocket مباشر بالنموذج المحدد، وموافقة جلسة مدفوعة وحد زمني وكتم وإيقاف.
- واجهة عربية ووسوم نطق تركية، وتوقف عند الخلفية والمقاطعات وفصل سماعات.

## التحقق الحالي

نجحت محليًا اختبارات Python للعدد والتفرّد والحقول وعقود الأمان، وفحص صياغة shell وgit diff --check. في [الجولة الأولى](https://github.com/dukkanai/turkish-scenes/actions/runs/42212953099) للنسخة ba55f59763865651690faad9aedad5a1ca846b18 نجحت اختبارات Swift لمحرك الدرس والتخزين والبروتوكول والنطق، وبناء المحاكي والتحقق من العربية. فشل assertion واحد في smoke لأن التحقق اعتمد لفظ رسالة التوقف بدل حالة الاتصال؛ أضيفت قيمة وصول صريحة للحالة مع تحقق بقاء زر البدء وعدم وجود زر الإيقاف بعد الإلغاء. لا يُعد الاختبار ناجحًا حتى إعادة تشغيله.

أضيفت اختبارات تنفيذية مستقلة لتسلسل خرج الصوت والمقاطعات والحدود، وحماية تجاهل الأحداث المتأخرة من ردود مقاطعة. يعيد مسار TestFlight كل هذه الفحوص وبناء المحاكي وsmoke على commit المرشح نفسه قبل الأرشفة والرفع. يبقى الرفع محجوبًا تلقائيًا إذا فشلت خطوة.

في [تشغيل TestFlight رقم 9](https://github.com/dukkanai/turkish-scenes/actions/runs/42227102294) للنسخة ff6d593280156910375e735013ba28a6f4229ab7، نجحت الفحوص الآلية وsmoke والأرشفة، لكن Apple رفضت الرفع 9.1 بسبب غياب أيقونة 120×120 ومفتاح CFBundleIconName. علامة GitHub الخضراء لم تثبت الرفع: أعادت altool رمز خروج صفر رغم رسائل الرفض ولم يجد التحقق البناء في Apple. لا تعد هذه النسخة مسلّمة.

إصلاح قيد التحقق: تضمين Resources في مشروع XcodeGen، فحص الأيقونة المجمّعة وبياناتها قبل الرفع، ورفض رسائل فشل Apple حتى مع رمز خروج صفر. نجاح تسليم TestFlight يتطلب أيضًا تأكيد معالجة النسخة وإتاحتها للمجموعة الداخلية؛ انتهاء مهلة التحقق لا يُعلن نجاحًا ولا يبرر إعادة الرفع.

نجح [CI للنسخة 0077d8f](https://github.com/dukkanai/turkish-scenes/actions/runs/42243710373) بما فيه فحص الأيقونة وsmoke. في [رفع رقم 10](https://github.com/dukkanai/turkish-scenes/actions/runs/42243700412)، نجحت الفحوص والأرشفة لكن فحص PNG المحلي أوقف المسار قبل الاتصال بـApple رغم توثيق Xcode تضمين AppIcon60x60@2x.png. الفحص كان يفترض أن IHDR أول مقطع بعد التوقيع، ولا يدعم CgBI الذي تستخدمه صور iOS المحسّنة؛ هذا هو السبب المرجح للاختلاف عن المحاكي. أضيف دعم هذا المقطع واختبارات تمنع قبول الصور المبتورة أو الأبعاد الخاطئة، وفحص أرشيف Release غير موقّع في CI مع توثيق نوع أول مقطع لإثبات النتيجة قبل التوقيع والرفع. لا توجد محاولة رفع إلى Apple من تشغيل رقم 10.

راجعت مراجعة مستقلة محلية دورة الصوت والأحداث وأصلحت انتقال callbacks بين الجلسات، وربطت التقييم بالسؤال والدور الصحيحين، ومنعت تكرار استدعاءات أدوات مرفوضة من إطلاق حلقة ردود مدفوعة.

- جلسة OpenAI حقيقية أو إتاحة النموذج في حساب المستخدم؛ لم تُجرَ استدعاءات API مدفوعة.
