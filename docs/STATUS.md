# حالة التنفيذ

آخر تحديث: 2026-11-06.

## المنفذ في المصدر

استُبدلت واجهة الأفلام بتجربة صوتية للكلمات والعبارات والقواعد. بقي اسم التطبيق ومعرفه وملفات تقدم المستخدم السابقة دون تغيير أو حذف. أزيلت مصادر تجربة الأفلام من النسخة الحالية؛ تاريخ Git يحتفظ بها.

- 1,280 مدخلًا لغويًا متفردًا، منها 1,210 كلمات مفردة و70 تركيبًا معجميًا، في 256 درسًا؛ و250 عبارة يومية منفصلة في 50 درسًا؛ و20 درس قواعد.
- أمثلة أصلية وترجمات عربية، مع مراجعة نصية آلية وليست اعتماد متحدث أصلي.
- محرك درس يتطلب إجابتين صحيحتين لكل عنصر، ويعيد الخطأ ويؤجل غير الواضح، مع معرفات تمنع احتساب تقييم مكرر أو قديم.
- حفظ ذري مستقل ونسخة سابقة وحماية من الكتابة فوق ملفات فاسدة؛ لا تسجيل للصوت أو نص الإجابات.
- مفتاح شخصي في Keychain، واتصال WebSocket مباشر بالنموذج المحدد، وموافقة جلسة مدفوعة وحد زمني وكتم وإيقاف.
- واجهة عربية ووسوم نطق تركية، وتوقف عند الخلفية والمقاطعات وفصل سماعات.

## التحقق الحالي

نجحت محليًا اختبارات Python للعدد والتفرّد والحقول وعقود الأمان، وفحص صياغة shell وgit diff --check. أضيفت اختبارات Swift لمحرك الدرس والتخزين والبروتوكول، واختبار واجهة لتصفح الدرس واستئنافه وإلغاء الاتصال المدفوع، لكنها تنتظر نتائج GitHub macOS لهذا commit.

راجعت مراجعة مستقلة محلية دورة الصوت والأحداث وأصلحت انتقال callbacks بين الجلسات، وربطت التقييم بالسؤال والدور الصحيحين، ومنعت تكرار استدعاءات أدوات مرفوضة من إطلاق حلقة ردود مدفوعة.
