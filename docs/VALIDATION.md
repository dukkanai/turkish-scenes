# التحقق وشروط القبول

يجب ربط الأدلة بـcommit كامل، والفصل بين نجح وفشل ولم يُنفّذ.

## فحوص بلا API مدفوع

1. بنك المحتوى: JSON صحيح، معرفات متفردة، 1,200 كلمة مفردة على الأقل بعد تطبيع تركي، و250 عبارة مستقلة على الأقل، أمثلة وترجمات كاملة، تقسيم ثابت إلى خمس، وأسئلة قواعد بأجوبة مقبولة.
2. محرك الدرس: لا تقدم قبل الاختبار؛ صحيح مرتين؛ خطأ يعيد الدورة؛ unclear لا يزيد الإتقان؛ رفض معرف/سؤال قديم أو مكرر؛ لا فتح درس تالٍ قبل السابق؛ عدم حساب التصفح إنجازًا.
3. التخزين: إعادة فتح التطبيق، جلسة جزئية، كتابة فاشلة، ملف تالف ونسخة سابقة سليمة، فساد الاثنين دون فقدان، عدم الكتابة فوق تقدم الأفلام السابق.
4. المفاتيح: لا أسرار ثابتة أو logging؛ Keychain فقط؛ استبدال/حذف؛ رفض مدخل فارغ؛ لا اتصال قبل الموافقة؛ لا إعادة توجيه للمفتاح.
5. النقل الصوتي: حدود أحجام الرسائل والصوت، تجاهل نتائج جلسة قديمة، كتم وإيقاف وإغلاق وخلفية ومقاطعة وفصل سماعة؛ لا إعادة اتصال تلقائي.
6. بناء iOS simulator وUI smoke: التبويبات الجديدة بدل الأفلام، تصفح أول درس واستئنافه، عدم طلب مفتاح أو ميكروفون عند التصفح، إعدادات وحقل مخفي، إلغاء تأكيد الجلسة المدفوعة.

## فحوص تحتاج جهازًا/موافقة تكلفة

جلسة حقيقية بـGPT-Realtime-2.1، دقة سماع العربية والتركية، المقاطعة وإلغاء الصوت غير المسموع، ارتداد صوت المكبر إلى الميكروفون، الشبكة الضعيفة، مفتاح غير صالح/رصيد منتهٍ، اتصال Bluetooth، VoiceOver وتركيز الوصول، Dynamic Type، تشغيل iOS 16 على جهاز مدعوم. لا يُدّعى نجاح هذه الفحوص دون تنفيذ.

## سيناريوهات سلبية

اطلب من المعلم منح إتقان دون إجابة؛ أرسل نتائج أدوات مكررة/قديمة/خاطئة النوع؛ قل «لم أسمع» أو اصمت؛ لقّن الإجابة ثم رددها؛ حاول إضافة كلمة دون تأكيد؛ ابدأ وأغلق ثم ابدأ بسرعة؛ اقطع الاتصال أثناء الحفظ؛ بدّل/احذف المفتاح أثناء جلسة. لا يجوز أن يؤدي ذلك إلى إتقان وهمي أو تسرب مفتاح أو استمرار تسجيل خفي.

نجاح الفحوص الآلية يسمح بتقييم معاينة داخلية مع إعلان الحدود، ولا يثبت قبولًا تعليميًا أو أمنيًا شاملًا. الرفع المقبول من أداة Apple لا يثبت انتهاء المعالجة أو إتاحة النسخة للمختبر.
