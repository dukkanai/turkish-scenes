# البنية والبيانات

## التطبيق

SwiftUI لتطبيق iPhone، مع `AudioLearningView` لواجهة التعلم الجديدة و`AudioLearningCore` لقواعد الدروس والتقدم. `AudioProgressStore` يحفظ JSON مستقلًا عن تقدم تجربة الأفلام، بكتابة ذرية ونسخة سابقة والتحقق قبل الاستعادة. فساد الملفين يمنع الاستبدال الصامت.

لكل عنصر معرف ثابت ونوع وفئة ونص تركي ومعنى عربي وأجوبة مقبولة ومثال وترجمته. للقاعدة شرح وسؤال وإجابات متوقعة وتصحيح. لا تُستخدم أعداد ظهور الكلمات في فيلم للوصول إلى حد المنهج الجديد.

## الاتصال الصوتي

النموذج المحدد هو `gpt-realtime-2.1`. توثق OpenAI الاتصال عبر WebSocket مع ترويسة Authorization. الاختيار الأولي اتصال iOS أصلي مباشر بمفتاح الشخص نفسه؛ لا تُضمن مفاتيح مالك التطبيق ولا تُنشأ خدمة وسيطة عامة.

`RealtimeAudioIO` يحوّل صوت الميكروفون إلى PCM 16-bit mono 24 kHz، ويشغّل خرج الصوت مع حدود للذاكرة. `RealtimeTutor` يعالج الاتصال والانقطاع والمقاطعة والحد الزمني والأحداث والأدوات. WebRTC موصى به رسميًا لمرونة شبكات الهاتف؛ جودة هذا المسار الأصلي يجب إثباتها بجهاز حقيقي، ولا تُستنتج من صحة المخطط.

الأدوات محصورة في بدء الاختبار وتقييم السؤال الحالي واقتراح كلمة. لا ملفات أو شبكة عامة أو صلاحيات إدارية للنموذج. معرّف السؤال المتجدد يمنع تقييمًا مكررًا أو قديمًا، ويلزم دور صوتي حقيقي قبل قبول تغيير من النموذج. لا تكون عبارته «حُفظ التقدم» دليلًا دون نجاح التخزين.
